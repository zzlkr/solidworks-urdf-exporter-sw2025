# SW2URDF SW2025 自定义版 1.7.11

关闭 SolidWorks，运行同版本安装包，再启动 SolidWorks。

1. 在总装中确认子装配体所用配置的覆盖质量属性已保存。
2. 在 SW 装配体树选择**子装配体这一项**，把整个实例关联到同一个 Link。该 Link 也可关联其他独立组件，SW 会合并计算。
3. 勾选 **“计算质量 / 惯量”**，点击“下一步：导出设置”。在 Link 详细参数页核对质量（kg）、质心（m）和惯量（kg·m²）。

整组覆盖值不能拆给多个 Link。如果先前保存过详细参数，进入配置页时请确认计算选项仍然勾选；只有重新进入详细参数页才会从模型读取。

构建和 99 项隔离检查通过。真实 SolidWorks 中的整组覆盖值读取及完整导出尚需实机确认。
