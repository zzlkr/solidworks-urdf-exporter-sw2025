# SW2URDF SW2025 自定义版 1.7.12

导出时，SolidWorks 曾在计算关节参考轴时退出。此版直接读取已命名的参考轴，避免读取时改变 SolidWorks 的选择列表。

1. 保存装配体并关闭 SolidWorks，运行 `sw2urdfSetup_SW2025_independent_autosave_v1.7.12.exe`。
2. 重新打开装配体，沿用原来的关节坐标系、关节轴及“计算关节运动学”选项，点击“下一步：导出设置”。
3. 核对关节轴方向和对应 Link 的质量，完成导出。本版已通过构建和 111 项隔离检查。在 SW 2025 的测试装配体上连续三次完成关节和质量计算。如果整机导出提示某个 Link 的坐标系失效，在该 Link 的“坐标系”中重新选择当前模型里对应的坐标系，再导出。

质量覆盖的配置步骤见 [1.7.11 使用说明](使用说明_v1.7.11.md)。
